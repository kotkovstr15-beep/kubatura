# Изменения по отчету Lighthouse от 02.09.2026

- Исправлен `ReferenceError: $ is not defined`: jQuery загружается до `ShowHead()`, поэтому доступен Bitrix-компонентам и их кешированным скриптам.
- Остальные плагины из прежнего `libs.min.js` вынесены в `js/vendor-deferred.min.js` и загружаются с `defer`.
- С главной страницы убран preload Montserrat Regular/Black, конкурировавший с приоритетной загрузкой LCP-изображения. Шрифты по-прежнему подключаются через `@font-face` с `font-display: swap`.
- Для WebP-версии логотипа установлено качество 68: это уменьшает файл, отмеченный Lighthouse, без изменения исходного PNG.
- После повторного замера Montserrat переведен на `font-display: optional`, чтобы поздняя загрузка четырех начертаний не создавала CLS в баннере.
- Для логотипа зарезервировано стабильное соотношение сторон 290:79 на всех контрольных ширинах.
- На главной вместо общего набора UI-плагинов загружается только Swiper; общий `common.js` заменен компактными `home-ui.js` и `home-slider.js`.

## После установки

1. Заменить каталог шаблона `/local/templates/s1/` содержимым этого каталога.
2. Очистить объединенный кеш CSS/JS Bitrix и композитный кеш.
3. Открыть главную страницу без авторизации и проверить консоль браузера.
4. Повторить Lighthouse для мобильного профиля. Полевые показатели CrUX обновляются постепенно за 28 дней.

Замечания про `bitrix.info/ba.js` и транспиляцию `/bitrix/js/main/core/core.min.js` относятся к ядру/внешнему ресурсу Bitrix и не исправляются подменой файлов шаблона.
