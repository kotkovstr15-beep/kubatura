Локальная доработка kubatura.su по ТЗ

1. Загрузить содержимое архива в корень сайта с сохранением структуры каталогов.
2. Сделать резервную копию файлов и базы данных.
3. Один раз выполнить из корня сайта:

   php local/tools/migrate-tz.php

Скрипт создаёт поле UF_INTRO у разделов каталога, HTML-поля DESC_MAIN, DESC_ASSORT и DESC_HELP у инфоблока магазинов и включает MANUFACTURER в фасетном индексе.

После миграции в административной части заполнить «Подводящий абзац» у нужных разделов каталога и три поля описания магазинов. Тексты страниц карты центра редактируются через включаемые файлы в include/karta-tssr/.

Автоматическое отключение товаров при деактивации магазина оставлено выключенным до проверки редиректов и запуска фоновой очереди. Для включения используйте настройки cascade_enabled и redirects_ready в php_interface/include/shop-page/config.php после проверки на копии сайта.
